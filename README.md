# Portfolio personale

Sito statico per raccogliere progetti, descrizioni e link alle repository GitHub.

## Modifiche rapide

1. Apri `script.js`.
2. Modifica la lista `projects` con titolo, descrizione, categoria e link.
3. Sostituisci i placeholder in `index.html` per nome e profilo GitHub.
4. Personalizza colori e dimensioni in `styles.css`.

Per visualizzarlo puoi aprire `index.html` direttamente nel browser oppure usare una semplice estensione come Live Server in VS Code.
